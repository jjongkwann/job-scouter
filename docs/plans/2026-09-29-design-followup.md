# 디자인 감사 후속 구현

기준: [독립 디자인 감사](../reviews/2026-09-29-design-expert-audit.md), [디자인 철학](../design.md).

근거 확인과 직접 판단, 지원 준비의 연속성을 유지합니다. 다섯 업무 영역과 기존 데이터 연결을 보존하며 정보의 순서·검색·문서 전환·실패 안내를 수정합니다. 색상이나 메뉴 체계를 다시 만들지 않습니다.

## 작업 분담

- `gpt-6-sol` / high: 이력서 작업 진입점과 수정 이력, 지원서류 탐색과 폴더 전환, 제안·파일 확인사항, 후보 검색과 요청 실패 안내를 나눠 구현합니다.
- `gpt-6-astra`: 모든 변경을 통합 검토하고 발견한 문제를 수정합니다.
- 메인: 실제 화면 검증, 전체 검사, mini 배포와 배포 결과 검증을 수행합니다.

## 완료 기준

| 감사 항목 | 확인할 결과 |
| --- | --- |
| 이력서 진입점 | 갱신 제안과 진행 중 대화가 긴 본문 앞에 보임 |
| 중요한 제약 | 제안 판단과 필수요건 차이, 파일 확인사항을 펼치기 없이 읽음 |
| 폴더 전환 | 같은 날짜의 폴더를 구별하고 문서 선택과 읽기 진입 위치를 유지 |
| 정보 밀도 | 1093px 목록과 상세가 관련 정보를 묶고 360px에서 넘치지 않음 |
| 검색 | 후보·초안·파일의 검색과 결과 수, 후보 상세 왕복 시 검색 복원 |
| 미연결 문서 | 확인된 상태만 설명하고 근거 없는 복구 방법을 안내하지 않음 |
| 수정 이력 | 선택 표시와 변경 내용 확인 뒤 해당 버전 복원 행동 제공 |
| 요청 실패 | 실패 이유와 선택 내용, 결과 확인 경로를 지속 표시 |

쓰기 동작은 가짜 API 테스트로 검증하고 운영 승인·제외·복원은 실행하지 않습니다. 배포 전후 후보·제안·파일 manifest 해시와 데이터 건수, Temporal 컨테이너를 비교합니다. 브라우저 증빙과 HTTP 검증 결과는 개인정보가 포함될 수 있어 Git에서 제외된 `data/design-followup-20260929/`에 보관합니다.
