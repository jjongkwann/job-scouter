# v4 Next.js 전환 구현 계획

> **For agentic workers:** 이 프로젝트는 `.claude/CLAUDE.md`대로 ponytail 규칙으로 구현한다(TDD 스킬·리뷰 의식 없음). 긴 계획이라 **태스크 하나당 서브에이전트 하나**. 체크박스(`- [ ]`)로 진행을 표시한다.

**Goal:** 데이터 repo에는 md·json만 남기고, 수집·계산·API는 `jobscouter/`, 화면은 `web/`(Next.js)이 맡는다.

**Architecture:** FastAPI(`jobscouter/api.py`)는 데이터 repo를 읽기 전용으로 마운트해 JSON·SSE만 내고, 쓰기는 전부 Temporal 워크플로 시작으로 위임한다. Next.js(`web/`)는 클라이언트 컴포넌트 + TanStack Query로 그리고, `/api/*`를 라우트 핸들러가 `api` 컨테이너로 통과시킨다. 추천도·통근·순위 계산은 파이썬 `candidates.py` 한 곳.

**Tech Stack:** Python 3.12 · FastAPI · temporalio · Next.js(App Router, standalone) · TypeScript · Tailwind v4 · shadcn/ui · TanStack Query v5 · react-markdown · vitest

**Spec:** `docs/specs/2026-08-27-v4-nextjs-design.md`

## Global Constraints

- 공개 저장소: IP·절대경로·데이터 repo 이름·회사명·집 위치를 코드·문서·테스트에 넣지 않는다. 테스트 픽스처는 `테스트회사`·중립 지명.
- 데이터 repo 레이아웃은 `config.py` 상수(`JOBFEED.parent` 기준)로만 참조.
- 데이터 스키마 불변: `candidates.json` 행 `[제목, 회사, id, [스택,도메인,레벨,역할(,감점)], 평판|null, 사유, 태그[], 마감(null|YYYY-MM-DD|closed)(, 주소)]`.
- API는 파일을 쓰지 않는다. 쓰기는 워크플로 시작만.
- `uv run pytest -q`가 항상 통과한 상태로 커밋. `web/`은 `npm run build`·`npx tsc --noEmit`·`npx vitest run` 통과.
- 화면 규격 유지: 시스템 고딕 14px · 최대 폭 1220px · 카드 radius 9px · 999px 필 · 4px 왼쪽 레일 = 평판.

```python
import json
import re
from datetime import date, datetime
from pathlib import Path
from zoneinfo import ZoneInfo

from jobscouter.config import APP_FILES, APPLICATIONS, JOBFEED, _norm, job_cid, settings

KST = ZoneInfo("Asia/Seoul")
MAX = [35, 25, 20, 20]
PENALTY_MIN = -25
_DATE = re.compile(r"\d{4}-\d{2}-\d{2}")
REP_MUL = {"good": 1.00, "warn": 0.88, "bad": 0.65, "none": 0.95}
REP_BONUS, REP_CONF = 0.12, 40      # good 보너스는 리뷰수/REP_CONF에 비례(상한 1)
ZONE_ADJ = {0: 8, 1: 3, 2: 0, 3: -12, 4: -45, 9: 0}
REP_LABEL = {"good": "괜찮음", "warn": "주의", "bad": "회피"}


def zone(addr: str | None) -> tuple[int, str]:
    """settings()['zones'] 순서대로 첫 매치. 비수도권 시·도를 맨 앞에 두는 건 데이터 쪽 책임."""
    if not addr:
        return (9, "미확인")
    for n, label, pat in settings()["zones"]:
        if re.search(pat, addr):
            return (int(n), label)
    return (9, "미확인")


def days_left(raw, today: date) -> int | None:
    if not raw or raw == "closed" or raw == "상시":
        return None
    try:
        return (date.fromisoformat(str(raw)[:10]) - today).days
    except ValueError:
        return None
```
`candidate_rows(today=None)`: `today = today or datetime.now(KST).date()`; 각 행 dict에 web.py 필드 전부 + `"days_left": days_left(r[7], today)`, `"url"`은 기존대로. `_rec`(반올림 전)는 dict에서 빼고 지역 변수로 순위만 매긴다(JSON에 안 실림). 평판 계수: `mul = 1.0 + REP_BONUS * min(conf / REP_CONF, 1) if k == "good" else REP_MUL[k]`.

`validate()`는 build.py `check()` 본문 그대로(오류 문구 포함).

```ts
import type { NextRequest } from 'next/server'
export const dynamic = 'force-dynamic'
const API = process.env.API_URL ?? 'http://localhost:8091'
const FWD = ['content-type', 'accept', 'sec-fetch-site']

async function proxy(req: NextRequest, ctx: { params: Promise<{ path: string[] }> }) {
  const { path } = await ctx.params
  const url = new URL(req.url)
  const headers = new Headers()
  for (const h of FWD) { const v = req.headers.get(h); if (v) headers.set(h, v) }
  const init: RequestInit & { duplex?: 'half' } = { method: req.method, headers, cache: 'no-store', signal: req.signal }
  if (req.method !== 'GET' && req.method !== 'HEAD') { init.body = req.body; init.duplex = 'half' }
  const res = await fetch(`${API}/api/${path.map(encodeURIComponent).join('/')}${url.search}`, init)
  const out = new Headers({ 'cache-control': 'no-store' })
  const ct = res.headers.get('content-type'); if (ct) out.set('content-type', ct)
  return new Response(res.body, { status: res.status, headers: out })
}
export { proxy as GET, proxy as POST }
```

```ts
export class ApiError extends Error { constructor(public status: number, public detail: string, public conflict = false) { super(detail) } }
async function call<T>(path: string, init?: RequestInit): Promise<T> {
  const r = await fetch(`/api${path}`, { ...init, headers: { 'content-type': 'application/json', ...(init?.headers ?? {}) } })
  if (!r.ok) { const j = await r.json().catch(() => ({})); throw new ApiError(r.status, j.detail ?? j.cause ?? r.statusText, !!j.conflict) }
  return r.json()
}
export const get = <T,>(path: string) => call<T>(path)
export const post = <T,>(path: string, body: unknown) => call<T>(path, { method: 'POST', body: JSON.stringify(body) })
```
